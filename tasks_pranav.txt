═══════════════════════════════════════════════════════════════
                    🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: "Port already in use" or "Address already in use"
Solution (Mac):
  lsof -ti:8080 | xargs kill -9
  Then restart server

Solution (Windows):
  netstat -ano | findstr :8080
  taskkill /PID <number_shown> /F
  Then restart server

───────────────────────────────────────────────────────────────

Problem: Can't connect to http://localhost:8080
Solution:
  1. Check server is running (terminal should show "running")
  2. Make sure you typed: http://localhost:8080 (not https)
  3. Try: http://127.0.0.1:8080
  4. Check firewall isn't blocking port 8080

───────────────────────────────────────────────────────────────

Problem: Server crashes on start
Solution:
  1. Check if port 8080 is free (see first problem)
  2. Check data/tasks.json exists and is valid JSON
  3. Try running with administrator/sudo permissions

───────────────────────────────────────────────────────────────

Problem: Tasks not saving
Solution:
  1. Check data/tasks.json file exists
  2. Check file permissions (should be writable)
  3. Check server terminal for error messages

═══════════════════════════════════════════════════════════════
                    💾 DATA PERSISTENCE
═══════════════════════════════════════════════════════════════

Your tasks are saved in: data/tasks.json

This file:
  ✓ Automatically saves when you add/edit/delete tasks
  ✓ Survives server restarts
  ✓ Survives computer restarts
  ✓ Can be backed up by copying the file

To start fresh:
  1. Stop server (Ctrl+C)
  2. Delete or rename data/tasks.json
  3. Restart server (creates new empty file)

To backup your tasks:
  Copy data/tasks.json to safe location
