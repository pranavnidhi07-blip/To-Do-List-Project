## 🐛 If Something Goes Wrong

### "Failed to fetch" error:
1. Check both servers are running:
   - Terminal should show: "Crow/master server is running"
   - Terminal should show: "Serving HTTP on"
2. Make sure you're at http://localhost:8081 (NOT file://)
3. Check browser console for specific error

### Port already in use:
```bash
pkill server && lsof -ti:8081 | xargs kill -9
./start.sh
```

### Tasks not appearing:
1. Refresh browser (Cmd+R)
2. Check: http://localhost:8080/api/tasks in browser
   - Should show JSON array
   - If empty, run `./add-sample-tasks.sh`

### Server stopped running:
- Don't run commands in the server terminal!
- Use a separate terminal tab for commands
- Keep server terminal open and running
