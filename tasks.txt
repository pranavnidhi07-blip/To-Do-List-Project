HOW USER SEPARATION WORKS:
---------------------------
- Each user has unique username (e.g., "alice")
- Server creates file: data/tasks_<username>.txt
- When user logs in, server switches to their file
- Function: task_service.set_current_user("alice")
  Changes file from tasks.txt → tasks_alice.txt
- All CRUD operations now work on that user's file only

SESSION MANAGEMENT:
-------------------
- Uses browser's sessionStorage
- Stores: current_user, display_name
- Checked on every page load
- Cleared on logout


================================================================================
COMMON QUESTIONS & ANSWERS
================================================================================

Q: Why .txt instead of .json?
A: Faculty requirement - JSON not in syllabus. Files use .txt extension but 
   contain structured data our C++ program can parse.

Q: How do you prevent users from seeing each other's tasks?
A: Physical file separation. Alice's tasks in tasks_alice.txt, Bob's in 
   tasks_bob.txt. Server only opens the logged-in user's file.

Q: What if username already exists?
A: System checks and shows error "Username already exists". Must choose unique.

Q: Is there password protection?
A: Not currently - focused on core multi-user functionality. Passwords would 
   be future enhancement using hashing.

Q: What happens if user closes browser?
A: Session cleared, must login again. But all tasks saved in their .txt file, 
   no data lost.


================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Compilation errors on Windows
SOLUTION: Make sure you ran these Windows setup commands:
   cmake -S . -B build -G "MinGW Makefiles"
   cmake --build build

PROBLEM: Login page doesn't show
SOLUTION: Make sure server is running first (build\server.exe)

PROBLEM: "Failed to fetch" errors
SOLUTION: Server crashed. Check terminal for error messages. Restart server.

PROBLEM: No users showing on login page
SOLUTION: Normal for first time! Create first user using "New User" tab.

PROBLEM: After creating user, still shows login page
SOLUTION: Clear browser cache and sessionStorage. Close and reopen browser.
